# Vextra - Minecraft Skin Editor

ブラウザ上で、3Dモデルに直接ペイントしてMinecraftのスキンを作れるエディタです。

## 特徴

- **3Dモデルに直接描画** — 展開図(UV)を意識せず、モデルの表面をクリック・ドラッグして描けます
- **素肌と上着(オーバーレイ)の2層に対応** — パーツごとに表示を切り替えて、描きたい層だけを編集できます
- **ミラー描画** — 左右対称の位置に同時に描けます
- **オートフォーカス** — 表示中のパーツに合わせてカメラが自動でズームします
- **自動保存** — 描いた内容はブラウザ(IndexedDB)に自動保存され、次に開いたときに同じ作品が開きます。ヘッダーで「保存済み / 保存中… / 保存失敗」が分かります
- **マイスキン** — 複数の作品を、サムネイル付きの一覧から開く・名前の変更・複製・削除ができます
- **Classic ⇄ Slim の変換** — 右サイドバーの「モデル」で、作品を今のままもう一方のモデルに変換できます。腕の絵を新しい展開図に移し、Undoで元に戻せます
- **新規メニュー** — 「素体から / 白紙から / PNGから」を、ワンクリックで選んで作り始められます。モデルは **Classic(腕4px) / Slim(腕3px)** から選べ、選んだほうは次回も覚えています
- **下地と手描きを分けて保持** — 読み込んだスキンや素体は下地として守られ、その上に描いた内容は別の層に入ります
- **PNGの読み込み・書き出し** — 既存のスキンを読み込んで編集し、PNGとして書き出せます。Classic / Slim は画像の中身から自動で判定し、旧形式 (64×32) のスキンも読み込めます

## 操作方法

### マウス

| 操作 | 動作 |
|---|---|
| モデル上で左ドラッグ | 描画 |
| 背景で左ドラッグ | 視点の回転 |
| ホイール | ズーム |

### キーボードショートカット

| キー | 動作 |
|---|---|
| `W` | ペン |
| `E` | 消しゴム |
| `F` | バケツ |
| `S` | スポイト |
| `1` / `2` / `3` | ブラシサイズ |
| `Ctrl` + `Z` | Undo |
| `Ctrl` + `Shift` + `Z` / `Ctrl` + `Y` | Redo |

macOSでは `Ctrl` の代わりに `Cmd` を使えます。

## 仕組み

スキンのデータは、3つの層(型付き配列)で持っています。

```
下地 (読み込んだスキン・素体)  ┐
手描き                       ├→ 重ねる (composite) → <canvas> → 3Dモデル / PNG書き出し
消去マスク                   ┘
```

1. モデルをクリックすると、Raycasterでクリック位置のUV座標を求める
2. UV座標を64×64のピクセル座標に変換し、手描きの層に描く
3. 3つの層を重ねた結果が `<canvas>` に書かれ、Three.jsの `CanvasTexture` として3Dモデルに反映される

```
src/
├─ App.tsx
├─ editor/
│  ├─ EditorLayout.tsx         画面全体。状態を持ち、各パネルと3D表示に配る
│  ├─ useKeyboardShortcuts.ts  キーボードショートカット
│  ├─ viewTypes.ts             表示の型 (パーツの表示/非表示・モード)
│  ├─ canvas/                  3つの層・描画ツール・Undo/Redo・PNGの読み込み
│  ├─ skin/                    スキンの形式そのもの (UVマッピング・ミラー対応表・素体)
│  ├─ three/                   3D表示 (モデル生成・Raycast・カメラ)
│  └─ components/              ボタンや各パネルのUI
├─ generator/                  スキン生成エンジン (設定とseedから64×64のスキンを作る。画面には未接続)
├─ projects/                   作品 (データ形式・IndexedDBへの保存・自動保存の順番待ち・一覧)
└─ shared/                     汎用処理 (色の変換)
e2e/                           ブラウザを動かして確かめるテスト (Playwright)
```

`src/**/*.test.ts` は Vitest のテスト (`npm test`)、`e2e/` は Playwright のテスト (`npm run test:e2e`) です。

## 現在の制限

- Classic → Slim の変換では、腕の外側の1列の絵が消えます (Undoで戻せます)。Slim → Classic は、外側の列を複製して足します
- モデルの自動判定は、腕の「使わない場所」を手がかりにした推測です。腕に絵が無いなど判断できない画像は、「新規」で選んでいるモデル(「読込」なら今のモデル)になります。違っていたら右サイドバーの「モデル」で変換してください
- 読み込めるのは64×64と64×32(旧形式)のPNGです。128×128などの高解像度スキンには未対応です
- 作品はブラウザごとの保存(IndexedDB)のため、別のブラウザや端末とは共有されません。大切な作品は「書き出し」でPNGにして残してください

## スキン生成エンジン (`src/generator/`)

「質問に答えるだけでスキンを作る」Quick Design の中身です。画面にはまだつながっていません (次の段階で接続します)。

```
設定 (SkinSpec) + seed ─→ 素材と段階を塗る ─→ 光と接触部分の影 ─→ 色 (素材ごとに5色) ─→ 64×64
```

- **同じ設定とseedなら、必ず同じスキン**になります (seed付き乱数。パーツごとに乱数の流れを分けているので、髪の描き方を変えても、服や顔は変わりません)
- 色はOKLCHで扱い、影は赤紫寄り・光は黄色寄りに色相をずらします (Hue Shifting)。素材ごとに5色に絞り、真っ黒・真っ白は使いません
- 陰影は、光の向きによる面ごとの明るさと、前髪の下・襟の下・袖口・脇・服の重なりなどの接触部分の影だけです。ノイズや「中心だけ明るい」陰影は使いません
- 髪は「髪束」の集まりで描き、前髪・横髪・後ろ髪を外側の層にも描いて奥行きを出します。ジャケット・パーカーのフードも外側の層です
- ClassicとSlimの両方に対応します (腕の幅は展開図から決まります)
